nahrávky doplnit cílovou firmu a Soukromá / Sdílená ve firmě. D11: nový stop-form
výchozí company; uložená volba a historický private fallback se zachovají;
explicitní volba položky nemění default účtu. Samotné nastavení nic neodesílá.

a vyžádej nový klik. Rozpracované a odeslané položky mají údaje zamčené.
