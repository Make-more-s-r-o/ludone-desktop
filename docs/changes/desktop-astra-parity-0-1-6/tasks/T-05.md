# Task T-05 — Nastavení, identity a aktualizace

Plan ID: `desktop-astra-parity-0-1-6` · závislost: T-04 dokončený.

## Výstup

Sjednotit vizuální jazyk nastavení, onboarding, update a identitu s Astra shell; zachovat stávající nastavení účtu, audia, retence, fronty, diagnostiky, tématu a updateru.

## Mantinely

- Hash `#settings` zůstává přesně zachovaný.
- Instalace aktualizace čeká na výslovné kliknutí uživatele a na bezpečné dokončení nahrávání.
- Použít stejnou originální LuDone značku jako zbytek LuDone; žádná nová cizí ikona/design.

## Akceptace a ověření

1. Všechna nastavení jsou dosažitelná a po zavření/obnově mají stejné chování jako před změnou.
2. Dostupný update ukazuje důvod, možnost instalovat a odložit; žádné samovolné restartování.
3. `npm run gates` a cílené settings/auth/update tests projdou.

## Output contract

Do `evidence/tasks/T-05.report.json` uložit doslovné kontroly, exit kód a `kontrolniNula` pro auth/permission drift.
