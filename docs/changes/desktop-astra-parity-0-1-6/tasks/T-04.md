## Tělo zadání

Plan ID: `desktop-astra-parity-0-1-6` · závislost: T-03 dokončený.

### Výstup

Postavit stopu dne podle Astry ze skutečně dostupné lokální queue a existujících serverem ověřených položek; detail poskytne jen současné povolené akce.

### Mantinely

- Znovu použít dashboard, queue a verifier; nebudovat druhou historii ani nový serverový endpoint.
- Neznámý/cizí/limitovaný stav nebarvit jako ověřený; při chybě zachovat lokální soubor.
- LuTrack část připravit kompozičně, nikoli funkčně.

### Akceptace a ověření

1. Prázdná data, čekající upload, odesláno-neověřeno, ověřeno, offline, vlastník/limit a chybějící soubor mají pravdivý obsah.
2. Tlačítka otevřít ve webu, ve Finderu, opakovat a bezpečně smazat respektují aktuální stav.
3. `npm run gates` a dashboard/queue/verifier testy projdou; záznam zůstává jedním stereo souborem.

### Output contract

Do `evidence/tasks/T-04.report.json` uložit výstup, `premisaPlatila`, `kontrolniNula` (server changes/fake entries/timer: 0) a exit kód.
