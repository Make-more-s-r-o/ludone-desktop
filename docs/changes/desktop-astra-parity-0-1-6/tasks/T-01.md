## Tělo zadání

Plan ID: `desktop-astra-parity-0-1-6` · výchozí task scaffold.

### Výstup

Potvrdit skutečnou mezeru mezi 0.1.5 a schválenou Astrou, uchovat původní prototyp v lokálním L2 artefaktu a sestavit intent, outcome contract, specifikaci, decision log a implementační plán.

### Dokončeno v tomto běhu

- Screenshot vydané aplikace byl porovnán s Astra `home`, `day`, `settings` a `identity` prototypy.
- Ověřeno, že manifest 0.1.5 výslovně realizoval pouze omezený výřez.
- Plná Astra HTML reference a assets byly zkopírovány do `artifacts/design/`; zdrojový návrh zůstává nedotčen.
- Zapsána hranice: skutečná nahrávka ano, demo data a LuTrack timer ne, backend mimo rozsah.

### Ověření

`shasum -a 256` potvrzuje bitovou shodu L2 `mockup.html` s `round2/variants/astra/index.html`. Výstup a pozdější schválení jsou archivovány v `evidence/masterplan/`.

### Output contract

Uložení důkazu o screenshotu z chatu označí, že originální dočasná příloha nebyla na disku dostupná. Neoznačovat release UI za „ověřeno“, dokud neproběhne T-06.
