## Tělo zadání

Plan ID: `desktop-astra-parity-0-1-6` · závislost: T-06 zelený, screenshoty vizuálně posouzené.

### Výstup

Review výsledného diffu, plné projektové brány, produkční build, PR s důkazy, následné podepsané vydání přes zavedený workflow pouze po green E2E.

### Mantinely

- Neoznačit automatické testy za live audio, upload, instalaci ani veřejný Mac test.
- Nepushovat release tag ani nespustit publikaci, pokud T5 nebo GUI review nejsou zelené.
- Nevyžadovat žádná tajemství v chatu; pokračovat jen stávajícím GitHub workflow.

### Akceptace a ověření

1. Bezpečnostní review zahrnuje všechny změny sender guard, queue, update a audio; pokud se do nich nesahalo, doloží se diff.
2. `npm run gates`, `npm run build`, T5 a CI projdou; PR odkaz je přiložen do úkolu.
3. Pokud runtime GUI nedovolí vizuální průchod, release zůstane čekající a finální postup pro Dana bude krátký a konkrétní.

### Output contract

Do `evidence/tasks/T-07.report.json` uložit doslovné testy, review nálezy, status PR/CI/release a `kontrolniNula` (neautorizovaný tag/publikace: 0).
## Postup — dodrž pořadí

1. Přečti zdroje, ověř dosavadní důkazy a dokonči pouze oprávněný rozsah etapy; chybějící schválení nebo release důkaz explicitně označ jako čekající.
2. Spusť typecheck příkazem `npm run typecheck` a uchovej doslovný výstup včetně exit kódu.
3. Spusť testy příkazem `npm run gates` a uchovej doslovný výstup včetně exit kódu.
4. Spusť `git --no-pager status --porcelain` jako jediný Git self-check a ověř zásahy proti allowlistu.
5. Odevzdej report přesně podle output contractu; žádný stav úkolu sám neoznačuj za dokončený.
