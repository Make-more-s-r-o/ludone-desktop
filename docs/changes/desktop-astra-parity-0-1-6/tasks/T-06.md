## Tělo zadání

Plan ID: `desktop-astra-parity-0-1-6` · závislost: T-05 dokončený.

### Výstup

Doplnění koordinátorem 30. 9.: stavová matice běží se zablokovanou sítí a lokálně injektovanou fixture místo preloadu. Hlavní Electron tok zůstává samostatný; žádná produkční oprávnění se nerozšiřují.

Samostatná bezpečná E2E brána pro hotový desktopový renderer, která projde primární Astra cestu, ověří obsah/interakce, pořídí pojmenované screenshoty a připraví přímé vizuální porovnání s `artifacts/design/mockup.html`.

### Mantinely

- Nespouštět produkční upload, nezapisovat přes síť a nepoužít skutečné tokeny.
- Testovací data zůstávají fixture mimo produkční store; test musí bezpečně uklidit vlastní procesy.
- Nepoužívat snapshoty jako automatickou výjimku; test detekuje chybějící stav, neklikatelné ovládání, oříznutí a rozdíl schváleného rozložení.
- `ui-smoke` zůstává zachovaný a jeho lidský Mac požadavek se nesnižuje.

### Akceptace a ověření

1. T5 vypíše samostatný PASS/FAIL pro Teď, záznam/uložení, Můj den, detail, Nastavení, update, offline/recovery, onboarding, light/dark a disabled LuTrack.
2. Screenshoty skutečného běžícího Electron rendereru mají stejné viewporty jako reference a kontrolují se vedle ní; rozdíl není prohlášen za pass jen kvůli textovým selektorům.
3. Neúspěch E2E znamená exit code nonzero; chybějící screenshot je FAIL.
4. `npm run gates`, `npm run build` a design E2E projdou v dostupném prostředí. Jakákoli nutná fyzická Mac kontrola zůstane explicitně 🟡.

## Sabotáže — spusť je, vypiš doslovný výstup

### MUSÍ ZČERVENAT

1. Chybějící screenshot, neklikatelné ovládání nebo nečekaný stav musí vrátit nenulový exit kód. Uchovej doslovný výstup negativního případu.

### MUSÍ ZŮSTAT ZELENÉ

1. Izolované syntetické zdroje a lokální uložená nahrávka projdou E2E bez produkčního uploadu. Uchovej doslovný výstup pozitivního případu.
