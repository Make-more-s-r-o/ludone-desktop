## Tělo zadání

Plan ID: `desktop-astra-parity-0-1-6` · závislost: T-01 dokončený.

### Cíl

Převést rychlou a větší plochu na stejný Astra shell s navigací „Teď“, „Můj den“, „Nastavení“, zachovat oddělené privilegované kontexty oken a přístupné klávesnicové ovládání.

### Rozsah

- `src/App.jsx`, `src/components/Settings.jsx`, `src/styles.css`.
- `electron/main.cjs` a `electron/preload.cjs` pouze pokud je třeba bezpečně změnit povolenou velikost nebo cestu mezi plochami.
- Nové testy pro validaci každé případné zprávy; existující IPC guard testy se nemění ani neoslabují.

### Akceptace

1. Navigace otevře odpovídající Teď/Můj den/Nastavení, funguje zpět i po zavření panelu a nepřeruší nahrávání.
2. Větší plocha dodrží proporce Astra při běžném i omezeném prostoru; neclipne ovládací prvky.
3. `#settings` a stávající oddělení capability zůstávají; nepovolený renderer nebo hash nemůže použít privileged IPC.
4. Všechny nové prvky mají přístupný název, focus stav a klávesnicovou navigaci.

### Ověření

`npm run gates` a cílené `tests/ipc-sender-guard.test.js`, `tests/settings.test.js`; později T-06 pokryje klikací Electron E2E.
