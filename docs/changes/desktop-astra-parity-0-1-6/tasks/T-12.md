## Úkol

Persistovat per-recording firmu a visibility. D11: pouze nově vytvořené nahrávky
v main finish/enqueue výslovně company; staré payloady/rows bez preference private. Normalizace,
restart a projekce nesmějí volbu zahodit. Pinned server firma má vždy přednost,
pak výslovná volba položky a potom default. Rozpracovaný upload neměnit.

Zpřístupnit úzký kontrakt pro formulář po zastavení a pro detail držené nahrávky.
Použít existující nabídku firem a zkontrolovat její čerstvost a scope před uložením;
per-recording volba nemění account default. Payloady explicitně validovat.
U detailu queue/file CAS a aktuální guard uvnitř serializovaného commitu.
Odmítnout veškerý server progress, aktivní/ukončovanou nahrávku a cizího vlastníka.
Preference musejí být na disku před approved intent. Nevytvořit druhé enqueue,
nezměnit clientRecordingId, server IDs, idempotenci ani bezpečnost retry.

Zachovat staré API payloady a jejich soukromý default. Zvol nejmenší rozšíření,
zdokumentuj přesné nové UI rozhraní v reportu; T-13 je závislý pracovník.
