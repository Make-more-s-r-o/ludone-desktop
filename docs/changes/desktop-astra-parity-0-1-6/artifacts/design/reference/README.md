# Referenční snímky schválené Astry

Těchto pět PNG je pevná vizuální reference pro lokální Electron E2E. Byly zachyceny z `docs/changes/desktop-redesign-2026-09-23/round2/variants/astra/index.html` dne 24. 9. 2026 při rozměrech uvedených v E2E skriptu. E2E je kopíruje do běhu a při každém běhu ověřuje shodu rozměrů; snímky se záměrně znovu negenerují jinou verzí Chromia.

Zdroj návrhu zůstává schválená varianta Astra. Referenční snímky jsou pouze benchmark vizuální struktury, ne zdroj produktových dat.
