# C — Nahrávač

🟡 Samostatný návrh k posouzení. Soustředí se na jeden hlavní krok: nahrát schůzku. Historie je další obrazovka, nastavení je sheet. Běžící nahrávání zůstává viditelné i v historii. Systémové písmo 15 px, názvy 16 px, metadata 13 px. Ikona LuDone zachovaná.

Ukázkových 44 nahrávek od dubna do října 2026 odpovídá datům A a B. Hledání, období, filtry, stránkování, detail a start/stop pracují jen v paměti.

⛔ Není implementace aplikace, připojení, autentizace, skutečného zvuku ani vydání. Maketové ovládání okna není nativní API. Čeká na schválení Dana.
