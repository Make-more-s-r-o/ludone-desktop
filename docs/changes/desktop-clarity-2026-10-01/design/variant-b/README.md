# B · Knihovna

🟡 Čeká na schválení návrhu. ⛔ Nejde o implementaci produktu ani vydání.

Samostatná maketa se stejnými 44 fiktivními nahrávkami jako varianta A. Postranní knihovna, filtrovaný seznam a trvalý inspektor; na úzkém okně samostatný detail s návratem. Výchozí září 2026. Hledání, období, stavy, stránkování, výběr detailu, nahrávací sheet a krátká nastavení fungují pouze v paměti. Akce nic neodesílají, neotvírají systémové aplikace a nenahrávají zvuk.

Systémové písmo, šedé plochy a zelený akcent hlavních akcí. Escape zavírá sheet a vrací fokus; klávesnice zůstává v otevřeném dialogu. Bez závislostí či napojení. `node --check preview.js` ověřuje syntaxi; skutečnou vizuální kontrolu návrhu provede koordinátor v prohlížeči.
