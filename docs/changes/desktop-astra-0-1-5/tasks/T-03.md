## Tělo zadání

### Final review a evidence

- **Pozorovatelné chování:** Výsledek lze zkontrolovat podle diffu, zelených bran, nezávislého review, CI, podepsaného vydání a veřejných aktualizačních metadat.
- **Invarianty:** Neoznačovat lokální build za podepsaný release; nečíst ani nevypisovat secrets; za živě ověřený zvuk, upload nebo update lze označit až Danovo skutečné pozorování na Macu.
- **Soubory:** Jen allowlist výše; plán a stav zůstávají pravdivé podle aktuálních důkazů.
- **Akceptace:** `npm run gates`, `npm run build`, `mp-lint --packet T-03.md` a `mp-progress --check` projdou; úplný lint zkontroluje i dokončené historické packety a každý nález bude uveden v evidenci.
- Samostatnou historickou bránu `scripts/akceptace/E5.sh` spusť také a její skutečný výsledek zapiš. Její sonda může být v rozporu s pozdějším schváleným chováním D3/D11; nic v bráně ani upload kódu kvůli tomu neměň. Rozpor popiš jako samostatné varování a vysvětli dopad na tento release.

### Vydání

- **Pozorovatelné chování:** Uživatel dostane verzi `0.1.5` přes zavedený podepsaný/notarizovaný workflow a aktualizační feed ukazuje metadata až po dokončení uploadu všech souborů.
- **Invarianty:** `latest-mac.yml` je publikováno jako poslední; nezměnit backend, server, tajemství ani publikační cestu; tag zveřejňuje koordinátor až po zeleném CI.
- **Soubory:** Release se spouští z existující `.github/workflows/release-macos.yml`; samotný worker nic nepublikuje a neprovádí zápis do Git.
- **Akceptace:** CI zelené, release workflow úspěšné, ověřovací skript potvrdí oba architektury i veřejný feed; Mac přejímka zůstává čekající.

## Postup — dodrž pořadí

1. Přečti uvedené upstream soubory a porovnej verzi, diff a evidence; nic mimo allowlist neupravuj.
2. Spusť `npm run typecheck`; uchovej doslovný výstup.
3. Spusť testy příkazem `npm run test:unit && npm run preskocene`; uchovej doslovný výstup.
4. Spusť `npm run build` a masterplan lint pro změnu a aktivní packet podle aktuálního skillu; ulož doslovné výstupy do povolené evidence.
5. Spusť `git --no-pager status --porcelain` jako závěrečný a jediný povolený Git self-check; ověř, že pracovní strom neobsahuje zápis mimo allowlist.
6. Po self-checku ulož report do `evidence/tasks/T-03.report.json` a odpověz podle output contractu.
