# Historický progress `desktop-v1`

Soubory `status.json` a `index.html` jsou zachovaný snapshot etapy z 7. 9. 2026. JSON používá starší české schéma a obsahuje 17 funkcí `DSK-F001` až `DSK-F017`. Není vstupem pro dnešní generátor schématu v2 a nesmí se převést slepým `mp-init --adopt`, protože by se tato funkční historie ztratila.

Aktuální autoritativní stav dokončení nahrávek je v [`../../nahravky-dashboard/progress/status.json`](../../nahravky-dashboard/progress/status.json) a jeho generované [HTML projekci](../../nahravky-dashboard/progress/index.html). Starý HTML přehled zde zůstává kvůli auditu tehdejšího stavu; tvrzení o Apple Developer Programu, GitHubu, uploadu a navazujících PR se nemají vykládat jako současná skutečnost.
