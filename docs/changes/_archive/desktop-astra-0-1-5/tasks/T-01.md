# Zadání T-01 — Značka a rychlý přístup k Nahrávkám

Pracuješ ve worktree `{{WORKTREE}}`; na začátku ověř `pwd`. Tento uzel je hotový a packet je archivní kontrolní záznam. Případné opakování vyžaduje nové rozhodnutí koordinátora.

## Mantinely

Nedělej zápisové Git operace; jediný povolený Git příkaz je závěrečný read-only `git --no-pager status --porcelain`. Příkazy nesmí čekat na vstup ani používat `stdin`. Nic neinstaluj. Nedělej žádnou výjimku z brány (`gateException`), nepoužívej `skip` ani zápis baseline místo opravy. Tento archivní packet už neopravňuje k zásahu do aplikace.

## Dokončený výsledek

- Z panelu vede jednoznačný vstup přímo do existujícího přehledu Nahrávek.
- Požadavek na záložku se validuje; bezpečnostní identita `#settings` zůstala zachovaná.
- Opakování žádosti po přihlášení rendereru neztratí vybranou záložku a tlačítko Nastavení se neduplikuje.
- Značka LuDone a nové stavové ikony odpovídají vybranému vzhledu; originální návrhy zůstávají uložené.

## Postup

Při případném opakovaném přezkoumání použij tento přesný postup:

1. Spusť `npm run typecheck`.
2. Spusť `npx vitest run tests/settings.test.js tests/queue-wiring.test.js tests/ipc-sender-guard.test.js tests/tray-ikony.test.js --reporter=dot`.
3. Spusť závěrečný a jediný povolený Git příkaz `git --no-pager status --porcelain`.
4. Odevzdej aktualizovaný JSON report do povolené cesty.
