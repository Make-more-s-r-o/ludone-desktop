# Zdroj současného pracovního toku

23. 9. 2026 — read-only pozorování uživatelem ukázané PWA LuDone přes accessibility strom. Otevřená aplikace běží jako macOS webová aplikace, její stránky jsou https://ludone.cz/time-tracking a https://ludone.cz/time-tracking/overview. V Chromu byl samostatně otevřený nový LuDone na labs.ludone.cz. Zdroj se tedy nesmí zaměnit s checkoutem nové aplikace.

Koordinátor přečetl aktuální přehled, přešel na Časovač a pokusil se pouze rozbalit výběr projektu. Ke změně hodnoty, spuštění/zastavení času, editaci, smazání, exportu ani uzávěrce nedošlo. Při oznámení změny aplikace uživatelem další ovládání skončilo. Management ani Admin nebyly proklikávané.

Pozorované typy informací a ovladačů jsou přepsané obecně do SHARED-BRIEF.md. Skutečné výkazy, sazby, názvy projektů, screenshot a osobní údaje se nekopírují. Přímá dostupnost desktopového API, oprávnění, datové schéma ani synchronizační chování nejsou tímto pozorováním ověřené. Úlohou kola je budoucí uživatelský zážitek.
