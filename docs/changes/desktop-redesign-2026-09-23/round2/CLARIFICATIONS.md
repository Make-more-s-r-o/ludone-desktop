# Společné upřesnění druhého kola

Doplnění po read-only review zadání Solem. Platí pro oba autory beze změny jejich estetické volnosti.

1. Fiktivní vazby: Web Studia Sever → Studio Sever; Interní rozvoj → Studio Sever; Podpora Ateliéru Jih → Ateliér Jih. Výchozí aktivní práce v working/meeting/save/offline/update je Web Studia Sever, popis Příprava obsahu; cílová firma nahrávky Studio Sever. Projekt→firma je kontext ukázky, není důkaz dnešního serverového kontraktu.
2. Při změně projektu zůstane u nahrávky původní kontext schůzky jako historická informace a její cílová firma se sama nezmění. Předchozí i nový pracovní úsek mají své projekty/popisy. Návrh může nabídnout výslovnou změnu souvislosti, ale nesmí zpětně přepsat historii bez viditelného rozhodnutí. Není požadováno rozdělování zvukového souboru ani přepis serverového schématu.
3. Jednotné pravidlo tohoto návrhu pro update: „Připravit“ může stáhnout simulovanou aktualizaci, **nikdy samo neautorizuje pozdější restart**. Při běhu času/zvuku/ukládání není instalace dostupná. Až jsou obě činnosti ukončené a uložení hotové, člověk výslovně klikne „Aktualizovat a restartovat“. Tím se předchází překvapivému restartu. Nahrazuje nejednoznačnou větu scénáře 9 o dřívějším souhlasu.
