# Druhé kolo — LuTrack a nahrávky jako jedna Mac aplikace

🟡 Astra a Claude Opus 5.5 připravují dva nezávislé návrhy podle stejného rozšířeného zadání. Sol zkontroloval zadání, koordinátor doplnil společná upřesnění. Nejde o implementaci ani vydání.

Dan 23. 9. požádal o celý uživatelský zážitek, kreativitu, širší zadání pro oba modely a prostor pro budoucí funkce. Toto kolo proto nahrazuje úzký rozsah prvního kola pro nové návrhy; první kolo zůstává zachované.

## Oprava podkladu o LuTracku

Současný živý LuTrack běží na https://ludone.cz/time-tracking jako samostatná PWA. Koordinátor read-only prohlédl Časovač a Přehled, bez měnění záznamů nebo zastavení času. Předchozí audit se týkal placeholderu v checkoutu nové app.ludone.cz; nelze z něj vyvozovat, že současný web LuTrack neexistuje. Dostupnost použitelného rozhraní pro nový desktop se v tomto designovém běhu neověřuje.

Všechny ukázkové osoby, firmy a časy v návrzích jsou fiktivní. Osobní screenshot a údaje z živé PWA nejsou součástí publikovatelných podkladů. Brockmann fonty jsou jen lokální a zůstávají mimo Git.

## Porovnání

A = Claude Opus 5.5; B = Astra. Jedno souvislé flow, čtrnáct vstupních situací a tři témata. Autoři volí vlastní šířku panelu i rozšířeného okna. Zobrazení vedle sebe / A / B umožňuje porovnat úkoly i skutečné proporce. Při širších oknech se návrhy složí pod sebe.
